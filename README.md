# きゅうくらりんリズムゲーム

[きゅうくらりん](https://www.nicovideo.jp/watch/sm39257413)のMVを模したリズムゲームである。
課題曲(音声ファイル)をアップロードすると、リズムの解析が行われる。
再生ボタンを押すと課題曲の再生が始まる。同時にマイクによる入力を受け付ける。
ユーザは再生中、手拍子や足踏みなどによってリズムを取ることができる。
そのリズムが、曲のリズムと一致するとMVが正常に作動する仕組み。

判定はリズム1回ごとに行う(=閾値以上の音圧が瞬間的に入力されるとトリガー)。これが曲の盛り上がりポイント・リズムに一致すればOK。一定のOK範囲外ならNG。だ。
OKであればきゅうくらりんのように画面上から画像が一枚降ってくる。
NGであれば画像は降ってこない。

画像の集団は時間経過(数秒に1度)一定距離左に移動していく。
移動はNGで画像が表示されなかった場合でも同様に左に移動する。

例えば、OK→NG→OKなら、NGの箇所だけ歯抜けになった状態で画像の集団が移動していく。
画面内に画像がなくなったらゲームオーバーである。

画像内に1枚以上画像が残っている状態で曲の再生を終えればクリアである。

画像は`./public`内の数字付き画像を用いる。1.pngから順番に登場させ、次の画像がなくなれば1に戻る。
アニメーションは`./Composition.json`を参照すること。(降ってくる→左に動く のセット。)3回OKが続いた場合の映像も`./Composition.mp4`に用意している。

実装はp5.jsを用いる。ビルドと配信にbunを、プログラムはtypescriptで記述する。

## プロトタイプの起動

```bash
bun install
bun run dev
```

ブラウザで音声ファイルを選ぶと、[`web-audio-beat-detector`](https://github.com/chrisguttandin/web-audio-beat-detector) が推定したBPM・先頭拍と、低・中・高域の音の立ち上がりを組み合わせてゲーム用のリズムポイントを生成する。テンポを推定できない曲では、音の立ち上がりだけを使う譜面へ自動的に戻る。

解析完了後に `MICを準備` を押し、短い入力調整が終わってから `START` を押す。曲が始まったら、リズムに合わせて手拍子する。マイクを使わない場合は、READY画面で `Space` を押すとそのまま開始でき、再生中の `Space` キーまたは画面タップを手拍子として判定する。

- `Space` / 画面タップ: 手拍子の代替入力
- `P` / `Esc`: 一時停止・再開
- `R`: リザルト画面からリトライ
- `O` / `U`: 別の曲を選択

マイク入力には `localhost` またはHTTPS環境が必要。スピーカー音を手拍子と誤検出しにくくするため、ヘッドホンでのプレイを推奨する。

ゲーム中は解析したリズムポイントごとに画像列が1段左へ移動し、OKのときだけ右端へ画像が落下する。開始直後の空状態ではゲームオーバーにせず、一度獲得した画像がすべて画面外へ流れた時点でゲームオーバーとする。曲の終了時に1枚以上残っていればクリア。
